# プライバシーポリシー

制定日：2026年9月12日  
最終更新日：2026年9月12日

Ashi@（以下「本サービス」）では、利用者のプライバシーに配慮し、必要な範囲で情報を取り扱います。


## 1. 個人情報について

本サービスは、ユーザーアカウントを必要としません。

そのため、本サービスを利用するために、氏名、住所、電話番号、メールアドレス、パスワードなどを登録する必要はありません。

また、本サービスは、Misskeyのアカウント情報、パスワード、アクセストークンなどの認証情報を取得・保存しません。


## 2. 位置情報について

本サービスでは、「あしあと」の作成や発見などのために、利用者の端末から位置情報を利用することがあります。

本サービスで利用する位置情報は、Ashi@のサーバーへ送信・保存されません。

そのため、本サービスの運営者が、本サービスを通じて利用者の現在地や移動履歴を把握することはありません。

ただし、「あしあと」をMisskeyへ投稿する場合、その投稿に含まれる位置情報はMisskey上の公開情報となります。

Misskeyなどの外部サービスでは、それぞれのサービスの仕組みに応じて位置情報が取り扱われる場合があります。


## 3. Misskeyの投稿について

本サービスは、Misskeyインスタンスおよびそれらと連合しているインスタンスに公開されたパブリックな投稿を参照します。

本サービスが参照する投稿には、投稿本文、投稿日時、投稿者名、画像などの公開情報が含まれる場合があります。

非公開投稿やダイレクトメッセージなど、本来公開されていない投稿を本サービスが取得することはありません。

Misskeyに公開された投稿は、Misskeyの仕組み上、利用者やその他の第三者によって閲覧、取得、解析、保存または再利用される可能性があります。

本サービスは、Misskey上の投稿そのものを削除したり、モデレーションを行ったりするものではありません。


## 4. アクセス時に記録される情報

本サービスへのアクセスに際して、利用しているサーバーやCDNなどにより、IPアドレス、アクセス日時、ブラウザや端末に関する情報、アクセスしたURLなどの技術的な情報が記録される場合があります。

これらの情報は、本サービスの提供、障害の調査、セキュリティ対策、不正利用の防止、アクセス制限などのために利用することがあります。

本サービスは、これらの情報を利用して、利用者の現在地や移動履歴を把握することを目的としていません。


## 5. Cookie・Local Storageなどについて

本サービスでは、設定の保存や機能の提供のために、CookieやLocal Storageなどのブラウザの機能を利用する場合があります。

Local Storageなどに保存される情報は、基本的に利用者の端末内に保存されます。

これらの機能を無効にした場合、一部の機能が正常に利用できなくなることがあります。


## 6. 外部サービスについて

本サービスでは、ホスティング、CDN、地図表示、Misskeyとの通信などのために、第三者が提供するサービスを利用する場合があります。

これらの外部サービスでは、それぞれのサービスの方針に基づいて、アクセス情報や位置情報などが取り扱われる場合があります。

外部サービスによる情報の取り扱いについては、それぞれのサービスが定めるプライバシーポリシーなどをご確認ください。


## 7. 情報の第三者提供について

本サービスは、法令に基づく場合などを除き、取得した情報を利用者の同意なく第三者へ提供することはありません。

ただし、本サービスの提供に必要なホスティング、CDNその他のサービスを利用する場合には、そのサービスの提供者に必要な情報が送信されることがあります。
